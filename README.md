# Top 200 Drug Study System

**Version:** v1.0.1  
**Dataset:** Top 200 (2026 Edition)

An adaptive desktop quiz application for mastering the Top 200 medications.

---

## Features

- Brand ↔ Generic testing
- Class testing
- Treatment testing
- Category testing
- Schedule testing
- Adaptive difficulty engine
- Category filtering
- Session question limits
- Retest missed questions
- Lifetime statistics tracking
- Corruption-safe JSON persistence
- Mac Apple Silicon build
- Mac Intel build

---

## Download

Go to the **Releases** section of this repository:

👉 https://github.com/grandpagreg/top-200-drug-quiz/releases

Download the correct version for your system:

- **Apple Silicon (M1/M2/M3)** → `Top-200-Drug-Quiz-Apple-Silicon.zip`
- **Intel Mac** → `Top-200-Drug-Quiz-Intel.zip`

After downloading:

1. Unzip the file.
2. Move the `.app` file to your Applications folder.
3. If macOS blocks it:
   - Right-click → Open.
